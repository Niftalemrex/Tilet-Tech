# Tilet Technologies

> **Zero-Trust Cybersecurity · Enterprise Cloud · Applied AI · High-Scale Web & Mobile Systems**

Tilet Technologies delivers elite digital defense, zero-trust architectures, and high-performance software engineering for enterprises and startups in Ethiopia and worldwide.

## Tech Stack & Core Pillars
- **Cybersecurity & Zero Trust**: Penetration Testing, SOC SIEM Monitoring, Cloud Security, DevSecOps, ISO 27001 / SOC 2 Compliance.
- **Enterprise Web & Cloud**: Next.js 16, React 19, TypeScript, Tailwind CSS, Node.js, Kubernetes, AWS, GCP, Azure.
- **Applied AI & ML**: Python, PyTorch, TensorFlow, Computer Vision, Custom Neural Models & LLM Integrations.
- **Mobile Platforms**: Native & Cross-Platform (Flutter, React Native, Swift, Kotlin).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Build for Production

```bash
npm run build
npm start
```
